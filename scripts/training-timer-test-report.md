# 訓練計時器測試紀錄 — 2026-10-27

測試範圍：正式站現行行為、本機修正版（PWA v22）。瀏覽器為 Codex 內建 Chromium，桌面畫面 1280 × 720。所有測試資料均由本次建立，未操作教練手機資料。

## 發現及修正

1. 暫停時跳過階段：內部換階段，畫面未重繪。現在立即顯示新階段、完整時間及組數，保持暫停。
2. 繼續前的三秒準備中再次暫停：覆蓋原本 resumePhase / pausedRemaining。現在保留原階段與剩餘時間。
3. 跳過確認框停留至自然換階段：確認後誤跳新階段。現在只處理開啟確認框時的同一階段，若已自然換階段則不再跳過。
4. 修改時間後改名：把未儲存設定誤標為已儲存，儲存按鈕失效。現在改名只更新名稱的儲存基準，其他未儲存設定仍可儲存。

## 限制及後續實機驗證

本次不是 iPhone Safari 或 Android Chrome 實機測試，也沒有宣稱所有階段的每一個按鈕組合都已在瀏覽器逐一點過；跨階段按鈕矩陣由上述程式測試補足。

尚未驗證：手機直向／橫向排版、手機實際語音、鎖屏及背景執行、螢幕常亮權限、斷網啟動、安裝 PWA、service worker 更新交接，以及長時間計時精準度。PWA 已提升到 v22，但版本更新本身不等同離線及安裝測試。
